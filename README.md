# Decidia

L'IA qui ose te dire non — aide à la décision par modèles mentaux + Océan Bleu.

## Démarrage

```bash
npm install
npm run dev        # http://localhost:3000 (page de démo du design system)
npm run typecheck && npm run lint && npm test && npm run build
```

Les étapes de développement suivent la section 10 du cahier des charges.
